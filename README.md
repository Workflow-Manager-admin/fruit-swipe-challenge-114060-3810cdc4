# Fruit Ninja - React Game

This project is a modern, animated Fruit Ninja slicing game written in React.
It includes interactive fruit slicing, animated effects, playful and vivid UI, and is fully responsive for desktop and mobile.

## How to Run

1. cd fruit_ninja_frontend_workspace/fruit_ninja_frontend
2. npm install
3. npm start

Play the fruit slicing game at http://localhost:3000/ !

> Modern UI, smooth animations, no backend needed. See fruit_ninja_frontend_workspace/fruit_ninja_frontend/README.md for full frontend details.
